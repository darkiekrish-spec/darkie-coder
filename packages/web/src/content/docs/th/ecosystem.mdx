ชุดโครงการชุมชนที่สร้างขึ้นบน Darkie Coder

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Darkie Coder ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-darkie-coder](https://github.com/awesome-darkie-coder/awesome-darkie-coder) และ [darkie-coder.cafe](https://darkie-coder.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
